## 🔧 Como Usar

### **Inicialização Básica**
```javascript
const { initializeCore } = require('@ai-agent/core');

const core = await initializeCore({
    security: { enableSandbox: true },
    network: { port: 8080 },
    sync: { compressionLevel: 6 },
    optimization: { learningRate: 0.01 }
});

// Usa componentes
await core.client.generateResponse('Hello!');
await core.memory.addMemory('test', { data: 'value' });
await core.network.connectToPeer('http://peer:8081');
await core.syncEngine.store('key', data);
await core.autoOptimization.optimize();
```

### **Configuração Avançada**
```javascript
const core = await initializeCore({
    security: {
        enableSandbox: true,
        enableEncryption: true,
        enableSigning: true
    },
    memory: {
        enableWAL: true,
        checkpointInterval: 30000
    },
    network: {
        port: 9090,
        heartbeatInterval: 15000
    },
    sync: {
        compressionLevel: 9,
        conflictResolution: 'semantic-merge'
    },
    optimization: {
        confidenceThreshold: 0.8,
        predictionHorizon: 7200000
    }
});
```
